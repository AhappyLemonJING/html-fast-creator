# HTML Fast Creator

这是一份用于验证转换效果的中文 Markdown 示例文档。

## 核心能力

- 本地转换，不需要上传文件。
- 输出为独立 HTML，可以直接离线打开。
- 支持主题、目录、封面和深浅模式。

## 代码示例

```ts
export function hello(name: string) {
  return `Hello, ${name}`
}
```
